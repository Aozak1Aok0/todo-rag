**一、增删元素**
- `unshift()`：在数组的最前面添加一个或多个元素，并返回新数组的长度。
- `shift()`：删除数组的第一个元素，并返回该被删除的元素。
- `pop()`：删除数组的最后一个元素，并返回该被删除的元素。
- `push()`：在数组的末尾添加一个或多个元素，并返回新数组的长度。

**二、截取与拼接**
- `splice()`：向数组中添加或从数组中删除指定位置的元素，会改变原数组。
- `slice()`：提取数组中指定位置的元素，返回一个新数组，不改变原数组。
- `concat()`：连接两个或多个数组，返回一个新数组，不改变原数组。

**三、转换与查找**
- `toString()`：将数组转换为字符串，默认使用逗号分隔。
- `join()`：将数组的所有元素连接成一个字符串，可指定分隔符。
- `split()`：将字符串按指定分隔符拆分成数组（这是字符串方法，常与数组方法配合使用）。
- `indexOf()`：返回数组中第一个找到的指定元素的索引，找不到则返回 -1。
- `includes()`：判断数组是否包含指定的元素，返回 true 或 false。
- `lastIndexOf()`：返回数组中最后一个找到的指定元素的索引，从后向前查找。

**四、条件查找与过滤**
- `findIndex()`：返回数组中第一个满足提供的测试函数的元素的索引，找不到则返回 -1。
- `find()`：返回数组中第一个满足提供的测试函数的元素的值，找不到则返回 undefined。
- `filter()`：过滤数组，返回所有满足测试函数的元素组成的新数组。
- `startWith()`：判断字符串是否以指定的子字符串开头，返回 true 或 false。
- `endsWith()`：判断字符串是否以指定的子字符串结尾，返回 true 或 false。


**五、遍历与迭代**
- `map()`：对数组中的每个元素执行回调函数，返回由结果组成的新数组。
- `reduce()`：对数组中的每个元素执行回调函数，将其结果汇总为单个返回值。
- `forEach()`：对数组中的每个元素执行一次提供的函数，没有返回值。
- `some()`：测试数组中是否至少有一个元素满足测试函数，返回 true 或 false。
- `every()`：测试数组中是否所有元素都满足测试函数，返回 true 或 false。

**六、排序与重排**
- `sort()`：对数组的元素进行排序（默认按字符串Unicode码点排序），会改变原数组。
- `reverse()`：将数组中元素的位置颠倒，返回该数组，会改变原数组。*/
