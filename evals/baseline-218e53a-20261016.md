返回 **400 Bad Request**，错误信息类似 `{"detail": "Todo name cannot be empty"}`。

**为什么不是 422：**

422 是 FastAPI/Pydantic 在**请求体结构校验失败**时返回的（比如字段缺失、类型不对、`name` 不是字符串）。而 `"   "`（三个空格）是一个**合法的字符串**，能通过 Pydantic 的类型校验，所以不会触发 422。

空/空白校验属于**业务逻辑校验**，是在路由处理函数内部手动做的：

```python
if not todo.name.strip():
    raise HTTPException(status_code=400, detail="Todo name cannot be empty")
```

`"   ".strip()` 得到空字符串，判定为无效，于是抛出 400。

**总结：**
- 422 = 格式/类型层面不合法（Pydantic 层）
- 400 = 格式合法但业务规则不满足（应用层）

如果你希望这种情况也返回 422，可以在 Pydantic 模型里用 `field_validator` 或 `constr(strip_whitespace=True, min_length=1)` 把校验前移到模型层。
